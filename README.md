# 联通 9929 VPS：先学会验回程再看价格，从年付入门款到 10Gbps 大带宽怎么挑

搜这个关键词的人，多半不是想听 AS9929 的来龙去脉，而是被同一个问题卡住过：明明买的是"联通优化线路"，晚上八点一过，延迟从 160ms 跳到 300ms，丢包开始出现，SSH 打字都有回声。于是开始怀疑是机器不行，还是自己买错了。

先给一个不绕弯的判断：9929 值钱的地方在回程，而 9929 最容易掺水的地方，也在回程。标了 9929 的机器，有可能只是出口借道了一两跳。

## 9929 到底是什么，为什么联通用户专门盯着它

AS9929 是中国联通的精品承载网，业内也叫 CUII、联通 A 网。联通跨境方向其实有三张网：AS4837（大家常说的 169 网，普通骨干）、AS10099（国际出口）、AS9929（精品网）[1]。普通联通宽带出国默认走 4837，晚高峰跟所有人挤同一条路；9929 是单独编号的自治系统，带宽资源和路由策略独立，定位上对标电信的 CN2 GIA[1][2]。

体感差异主要体现在两个时段上：

- 美西方向，9929 节点延迟通常在 150–180ms 区间，晚高峰波动不大；普通线路晚高峰实测能冲到 300ms 以上，丢包超过 5%[2]。
- 丢包率差距更明显。9929 整体多在 0.1%–1% 之间，普通线路晚高峰 5%–10% 是常见水平[1]。
- 日本方向如果是 9929，白天非高峰可以低到 35–45ms，晚高峰约 50–60ms，抖动控制在 5ms 以内[1]。

9929 的成本也在这里。它的带宽成本是普通国际带宽的数倍，主要覆盖北美、欧洲、日本方向，跨境互联端点数量比 4837 少[1]。这句话翻译过来就是：便宜得离谱的"9929 VPS"，大概率有问题。

## "联通优化"和"全程 9929"是两码事

买之前先认清三个常见的坑，能省下不少试错钱。

**第一个坑是借道。** 真正的 9929 线路，在路由追踪里能看到连续多跳的 AS9929 节点。不少低价套餐只有出口一两跳经过 9929，数据主体仍然跑在 4837 上[3]。这类机器的 ping 值看着还行，一到高峰期原形毕露。

**第二个坑是超售。** 9929 带宽贵，商家如果按普通线路的价格卖给你，通常意味着这台上面的实际并发远超合理水位。同一个机房的编号、同样的 CPU 型号，价格低到离谱的那一档，值得多问一句。

**第三个坑是把去程和回程混为一谈。** 去程走 4837、回程走 9929 是很常见的组合，反过来也有。你 ping 出来的延迟只能反映其中一段，看不出全程的路径质量。

## 买之前，自己跑一遍 MTR

商家宣传是一回事，路由追踪是另一回事。收货当天花五分钟跑一下，比看十篇推荐文都管用。

1. SSH 登录服务器，安装 traceroute 或 mtr：`apt install traceroute -y`。
2. 用本机 IP 测回程：`traceroute 你的本地IP`，或者用 `mtr -r 你的本地IP` 持续观察。
3. 想更省事可以装 `nexttrace`，它能直接识别 ASN；也有现成的一键脚本（如 besttrace.sh）可以自动标注线路类型[4][3]。
4. 在 Windows 本机执行 `tracert VPS_IP`，看的是去程；要注意去程和回程是两条路径，最好分别测。
5. 判断标准很简单：路径里必须出现 AS9929。如果只看到 AS4837 或 AS4134，说明这不是纯 9929。AS9929 的节点 IP 通常以 218.105 或 210.51 开头[1]。

另外，测的时候一定要分运营商测。你用联通宽带测出来的是联通方向，电信和移动方向要另外找人测或者用现成的三网监控。

## 挑 9929 VPS 时，比价格更该看的几个参数

**回程优先于去程。** 你访问服务器的体验主要由回程决定，所以"三网回程 9929"的说服力大于"去程优化"。

**端口带宽和月流量要一起看。** 同样是 9929，有的机器给 500Mbps 配 1TB 流量，有的给 10Gbps 配 10TB。跑代理、跑推流、跑下载，需求完全不同。

**超量之后怎么处理，比流量多少更影响心情。** 常见做法有三种：直接断网、按量计费、限速不停机。限速不停机对个人用户最友好，至少机器还在线。

**IP 更换政策值得单独确认。** 做代理类用途的人，IP 被墙是迟早的事。能免费换、多久能换一次、超出之后怎么收费，这些要提前问清楚。

**机房位置按用户分布选。** 用户集中在华南，香港优先；面向全国且带宽需求大，日本和美西更平衡。

## 几个高频问题

**9929 和 CN2 GIA 到底差多少？**
服务对象不同。CN2 GIA 主要照顾电信用户，9929 是联通定向优化[1]。延迟上 CN2 GIA 通常 120–150ms，9929 约 150–180ms；丢包两者都在 1% 以内，非高峰时段差距不大[1]。电信用户没必要为了 9929 放弃 CN2 GIA。

**电信或移动宽带的用户，买 9929 有意义吗？**
去程不一定走 9929，所以体验不如对应运营商的精品线路直接。不过现在不少方案是三网混合：电信走 CN2 GIA、联通走 9929、移动走 CMIN2，回程统一走高端线路[1]。买之前看清楚"回程"两个字后面写的是什么。

**9929 的机器能建站吗？**
可以。9929 的优势是延迟稳定和抖动小，建站受益的点在于访问体验一致性。但注意流量跑完之后是限速不是断网，限速到 4Mbps 的档位跑图片站会比较难受。

**需要备案吗？**
海外机房不涉及国内备案流程，域名解析过去直接用。这是这类机器被国内站长选择的原因之一。

**为什么同一档配置会有三个价格？**
平台不同。AS3 是 EPYC 7003，AN4 是 9004，AN5 是 9005，发布时间越晚的单核性能越强，价格也越高。低配用途多花的钱感知不强，高并发场景才值得为新一代平台加钱。
